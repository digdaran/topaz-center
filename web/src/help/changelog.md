# Что нового

## 1.6.2 — 01.11.2026

**Новое**
- Раздел **«Помощь»** в меню: инструкция по работе с сервисом и эта страница «Что нового». Когда выходит обновление, у пункта «Помощь» появляется метка «новое».

## 1.6.1 — 01.11.2026

**Исправлено**
- Пропали ложные события «Разрыв счётчика» на сотни тысяч литров. Они появлялись, пока у новой АЗС догружалась история, и были вызваны сравнением со старой сменой вместо предыдущей.
- Переход счётчика колонки через 999 999 → 0 больше не считается расхождением с заказами.
- События по счётчикам, которые данные больше не подтверждают, исчезают сами.

## 1.6.0 — 01.11.2026

**Новое**
- **Себестоимость топлива по средней цене резервуара.** При каждом сливе цена литра пересчитывается с учётом топлива, которое уже было в резервуаре, — маржа больше не скачет после сливов. Пример: было 8 000 л по 50 ₽, слили 10 000 л по 55 ₽ — литр стоит 52,78 ₽.
- **Напоминание «Не введена цена слива».** Если цену слива не ввели за сутки, появляется событие в «Контроле» и сообщение в Telegram; счётчик у пункта «Себестоимость» и подсказка на «Обзоре» показывают, сколько сливов ждут цену. В списке сливов есть фильтр «Без цены».
- **«Цена остатка на дату»** — по какой цене было топливо в резервуаре, например на начало учёта.
- **Маржа с НДС или без** — выбирается в «Настройки → Маржа и НДС». Без НДС налог вычитается из продаж с чеком. На «Финансах» видна доля выручки с чеком.
- **Скидки по дисконтным картам** теперь видны в отчётах, даже если Топаз не записывает их отдельно.
- **«Настройки → Виды оплаты»** — какие виды оплаты дают скидку (определяется по названию, можно исправить).

**Исправлено**
- Событие «Цена заказа ≠ цене ТРК» больше не срабатывает на скидки по картам. Теперь оно сообщает только о настоящих проблемах: клиент заплатил больше, сумма не сходится с ценой колонки или цену снизили мимо скидок Топаза.

## 1.4.0 — 01.11.2026

- Агент для АЗС ставится одним файлом: двойной щелчок, название АЗС, «Установить». В конце показывается код подтверждения для подключения.

## 1.3.0 — 01.11.2026

**Новое**
- Новая АЗС подключается по заявке: установщик показывает код, администратор сверяет его и подтверждает подключение. Общих ключей доступа больше нет.

## 1.2.0 — 1.2.2 — 01.11.2026

- Агенты на АЗС обновляются сами: сначала на пилотных АЗС, потом на остальных.

## 1.1.0 — 01.11.2026

**Новое**

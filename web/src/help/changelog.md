## 1.10.0 — 12.11.2026

**Новое**
- Уведомления в Telegram подключаются одной кнопкой, без номера чата. Лично себе: **Настройки → Вход и защита → Уведомления в Telegram → «Подключить Telegram»**, затем в Telegram **«Запустить»**. Так может сделать любой сотрудник: управляющий получает события только по своим АЗС.
- В группу: **Контроль → Уведомления в Telegram → «Добавить бота в группу»** — выберите группу в Telegram, и она появится в списке сама.
- Если бота удалили из группы или заблокировали в Telegram, сервис перестаёт туда писать и помечает чат «выключен».

## 1.9.0 — 12.11.2026

## 1.7.0 — 01.11.2026

**Новое**
- **Способы оплаты:** наличные, банковские карты, по договору (ведомости), топливные карты. Сервис определяет способ по названию вида оплаты на каждой АЗС; проверить и исправить можно в «Настройки → Виды оплаты». Там же подсказка, проводит ли Топаз эти отпуски через кассу.
- **Фильтр «Способ оплаты»** на «Обзоре», «Топливе», «Спросе», «Финансах» и в сравнении АЗС — например, все отчёты только по клиентам-договорникам.
- **Финансы → Продажи по договорам** — литры и суммы по ведомостям и топливным картам по АЗС, месяцам и видам топлива, с выгрузкой в Excel.
- На «Обзоре» — плитка «Продажи по договорам», в сменах — колонки «Карты» и «Договоры».
- Маржа без НДС: НДС вычитается и из продаж по договорам и топливным картам — по ним выставляются документы с НДС.
- **Уровнемеры в «Запасах топлива».** У резервуаров с электронным уровнемером — метка «уровнемер» и последний замер, у остальных — «по учёту». Новые блоки: потери по замерам за период по каждому резервуару, график потерь нарастающим итогом, учёт и замер по каждой смене.
- **Новые события «Контроля»:** «Недостача по замеру» — замер при закрытии смены меньше учёта больше чем на 20 л; «Излишек по замеру» — больше учёта больше чем на 200 л, чаще всего это слив, не оформленный в Топазе.

**Исправлено**
- На АЗС, где Топаз записывает оплату картой и по ведомостям как наличную (без пометки «Б»), такие продажи больше не считаются наличными. Доля безнала и «деньги по дням» теперь верные.

## 1.6.0 — 01.11.2026

**Новое**
- **Себестоимость топлива по средней цене резервуара.** При каждом сливе цена литра пересчитывается с учётом топлива, которое уже было в резервуаре, — маржа больше не скачет после сливов. Пример: было 8 000 л по 50 ₽, слили 10 000 л по 55 ₽ — литр стоит 52,78 ₽.
- **Напоминание «Не введена цена слива».** Если цену слива не ввели за сутки, появляется событие в «Контроле» и сообщение в Telegram; счётчик у пункта «Себестоимость» и подсказка на «Обзоре» показывают, сколько сливов ждут цену. В списке сливов есть фильтр «Без цены».
- **«Цена остатка на дату»** — по какой цене было топливо в резервуаре, например на начало учёта.
- **Маржа с НДС или без** — выбирается в «Настройки → Маржа и НДС». Без НДС налог вычитается из продаж с чеком. На «Финансах» видна доля выручки с чеком.
- **Скидки по дисконтным картам** теперь видны в отчётах, даже если Топаз не записывает их отдельно.
- **«Настройки → Виды оплаты»** — какие виды оплаты дают скидку (определяется по названию, можно исправить).

**Исправлено**
- Событие «Цена заказа ≠ цене ТРК» больше не срабатывает на скидки по картам. Теперь оно сообщает только о настоящих проблемах: клиент заплатил больше, сумма не сходится с ценой колонки или цену снизили мимо скидок Топаза.

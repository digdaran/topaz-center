# Агент АЗС: установка

**Требования:** Windows 10/11 или Server 2016+ x64 (для 32-битных систем есть сборка `win-x86`). **Windows 7 не поддерживается** — это ограничение .NET 8. Устанавливать .NET не нужно: агент поставляется одним exe-файлом. Нужен доступ к Firebird Топаза (обычно `127.0.0.1:3050`) и исходящий HTTPS к серверу.

Агент **только читает** базу Топаза: все запросы — `SELECT` в read-only транзакции. Входящих портов он не открывает.

## Установка

1. Скачайте **`TopazAgent-Setup-<версия>-win-x64.exe`** (для 32-битной Windows — `-win-x86`) со страницы [Releases](https://github.com/digdaran/topaz-center/releases/latest).
2. Запустите файл двойным кликом и разрешите изменения (запрос администратора Windows).
   Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Файл без цифровой подписи Microsoft, см. ниже.
3. В окне введите **название АЗС** и нажмите «Установить». Установщик сам:
   - найдёт базу Топаза в `C:\Program Files (x86)\TopazAZS-*\TopazAZS.fdb` (если не нашёл — «Выбрать…»);
   - проверит доступ к ней;
   - установит службу и отправит заявку на сервер.
4. В конце окно покажет **код подтверждения**, например `K7Q4-9MXD`. Сообщите его администратору сервера по телефону или в мессенджере. Он сверит код и одобрит АЗС в разделе «АЗС → Подключение». Через минуту агент начнёт передавать всё, что накопил с момента установки.

Свёрнутый блок **«Дополнительно»** в окне:
- сервер (по умолчанию `https://topaz.08u.ru`);
- путь к базе;
- пароль Firebird. По умолчанию используется стандартный пароль Топаза. Если Firebird его не принял, окно попросит ввести правильный.

Пароль хранится только в переменных окружения службы, в файлах настроек и журналах его нет. Порт Firebird 3050 наружу не открывайте.

**Что получается после установки:**
- служба «Topaz Center: агент АЗС» (автозапуск, перезапуск при сбое);
- программа в `C:\Program Files\TopazAgent`;
- очередь и журналы в `%ProgramData%\TopazAgent` — доступ только у SYSTEM и администраторов;
- ярлык **«Topaz Center — агент АЗС»** в меню «Пуск». Он открывает окно состояния: подключена ли АЗС, код подтверждения, журнал, изменение настроек, удаление;
- запись в **«Программах и компонентах»** — удаление штатным способом Windows.

**Повторный запуск установщика** на той же АЗС обновляет агент. Название, сервер и база сохраняются, менять их не обязательно.

Если заявка истекла (14 дней) или была отклонена, агент сам пришлёт новую с новым кодом (после отклонения — через сутки). Код всегда виден в окне состояния.

### Тихая установка (для скриптов и массовой установки)

```bat
TopazAgent-Setup-1.4.0-win-x64.exe /S /station="АЗС-5 Северная" [/server=https://…] [/db="D:\Topaz\TopazAZS.fdb"] [/fbpassword=…] [/fbhost=…] [/fbport=3050] [/tz="Ekaterinburg Standard Time"]
```

- **Коды выхода:** 0 — установлено; 1 — установлено с замечаниями (например, нет связи с сервером или база пока недоступна); 2 — ошибка.
- **Код подтверждения и ход установки** пишутся в `%ProgramData%\TopazAgent\logs\setup.log`.
- В `cmd` используйте `start /wait`, в PowerShell — `Start-Process -Wait -PassThru`: установщик — оконное приложение.
- **Удаление:** `"C:\Program Files\TopazAgent\TopazAgent.exe" uninstall /S`. С `/removestate` удаляется и неотправленная очередь.

**Цифровая подпись.** Наш установщик подписан только нашей подписью пакетов обновлений, сертификата подписи кода Microsoft (Authenticode) у него нет. Поэтому Windows SmartScreen предупреждает при первом запуске скачанного файла. Убрать предупреждение можно, купив сертификат подписи кода; подключить его в сборку можно позже.

Установщик делает то, что раньше делали `install.ps1` и `uninstall.ps1`. Их больше нет.

## Команды

```powershell
& "C:\Program Files\TopazAgent\TopazAgent.exe" check          # конфиг, БД Топаза, связь с сервером, заявка и код
& "C:\Program Files\TopazAgent\TopazAgent.exe" status         # очередь, курсоры, dead-letter
& "C:\Program Files\TopazAgent\TopazAgent.exe" requeue-dead   # вернуть отклонённые пакеты в очередь
Get-Content "$env:ProgramData\TopazAgent\logs\agent-$(Get-Date -f yyyyMMdd).log" -Tail 50
```

`check` и `status` читают те же переменные окружения, что и служба. При ручном запуске `check` после установки задайте их в сессии (`$env:TOPAZ_AGENT_Firebird__Password = '...'`).

## Автообновление

Начиная с версии 1.2 агент обновляется сам. Новая версия приходит вместе с обновлением сервера (`setup.sh`), доступ АЗС к GitHub не нужен.

1. Сервер предлагает новую версию в ответ на heartbeat — по правилам раскатки из раздела **АЗС → Обновление агентов**: сначала пилотные АЗС, остальные позже.
2. Агент скачивает пакет со своего сервера и проверяет **цифровую подпись**. Пакеты подписываются при сборке на GitHub ключом, которого на сервере нет, а открытый ключ встроен в агент. Поэтому даже взломанный сервер не сможет подсунуть агенту чужой exe.
3. Агент распаковывает пакет в `%ProgramData%\TopazAgent\updates\<версия>` и запускает установщик одноразовой задачей планировщика от имени SYSTEM (`TopazAgentUpdate`).
4. Установщик:
   - останавливает службу;
   - сохраняет прежние файлы в `updates\backup`;
   - копирует новые: `appsettings.json` и пароли не трогаются, `datasets.json` заменяется, а прежний сохраняется как `datasets.json.bak`;
   - запускает службу.
5. Если новая версия за 3 минуты не вышла на связь с сервером, установщик **возвращает прежнюю версию**. Сервер показывает ошибку, а в «Контроле» появляется событие. Неудачную версию агент пробует снова не чаще раза в сутки, всего до 3 раз.

Очередь данных при обновлении не теряется. Служба стоит меньше минуты, данные за это время остаются в Топазе и будут прочитаны.

- Журнал установки: `%ProgramData%\TopazAgent\logs\update-<версия>.log`.
- Отключить автообновление на одной АЗС: на сервере группа «не обновлять» или локально `TOPAZ_AGENT_Updates__Enabled=false`.

**Агенты 1.0 и 1.1 автообновления не умеют:** один раз запустите на такой АЗС установщик новой версии. Дальше обновления придут сами.

## Что агент сообщает о ПК АЗС

С версии 1.2.1 агент вместе с heartbeat присылает (раздел **АЗС**, столбец «ПК АЗС»):
- свободное и общее место на диске с базой Топаза и на системном диске;
- размер файла базы Топаза — только по данным файловой системы, сам файл не открывается;
- время на ПК и часовой пояс Windows. Сервер сравнивает их с точным временем: Топаз записывает время операций по этим часам;
- время работы Windows и версию ОС.

Данных продаж, паролей и содержимого файлов среди этого нет. Если базы нет на этом ПК (Firebird на другом компьютере или указан алиас), её размер и диск не сообщаются.

## Обновление вручную и переустановка

- **Обновление вручную:** запустите установщик новой версии и нажмите «Обновить». Очередь, состояние и настройки сохраняются. `datasets.json` заменяется, прежний, если он отличался, сохраняется как `datasets.json.bak`.
- **Переустановка на другой ПК или с чистым состоянием:** установите агент как обычно. Придёт новая заявка — администратор одобряет её как «существующая АЗС». История сохранится, прежний доступ перестанет действовать, агент перечитает данные, а сервер не создаст дублей.
- **Удаление:** «Программы и компоненты» → «Topaz Center — агент АЗС», кнопка «Удалить агент…» в окне состояния или `TopazAgent.exe uninstall /S [/removestate]`.

## Настройки (`appsettings.json`)

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `Collection:IntervalSeconds` | 60 | период чтения смен и журналов |
| `Collection:SnapshotIntervalSeconds` | 900 | период чтения справочников |
| `Collection:ClosedSessionsWindow` | 3 | сколько последних закрытых смен перечитывать каждый цикл |
| `Collection:FullRescanHours` | 24 | полный перепроход всех смен (уходят только изменения) |
| `Collection:MaxItemsPerBatch` | 500 | строк в пакете |
| `Collection:MaxQueueBytes` | 2 ГБ | выше этого сбор на паузе (данные остаются в Топазе) |
| `Server:RetryMaxSeconds` | 900 | максимальная пауза между повторами |

Любой ключ можно переопределить переменной окружения `TOPAZ_AGENT_<Секция>__<Ключ>`.
